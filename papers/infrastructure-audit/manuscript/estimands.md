# What each analysis bounds: the allowed claims

The interpretation specification for this paper. Every rendering (article, supplement, brief, agent
guide) states each result only in these terms. The collaborators maintain it jointly; change it before
changing the prose, and agree it before writing analysis code that it governs.

A sentence passes only if its subject is the same object as the calculation. A caveat attached to a
sentence does not rescue it if its noun has changed, for example from a fossil-category endpoint to an
origin.

## RESULT NAME (claims Cxx–Cyy)

- **Estimand:** what the calculation targets, under which conditions (model, units, inputs, scale).
- **Allowed:** the phrasings that match it, with the conditions that must travel with them.
- **Not allowed:** the tempting overstatements, quoted, so a reviewer can search for them.
