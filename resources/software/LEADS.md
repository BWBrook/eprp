# Leads for the question registers

Capabilities found while cataloguing software that bear on register
questions or suggest new ones. The registers belong to the main EPRP agents;
leads reach them as a tranche note on the board, at Barry's direction.
Each lead is labelled `checked` (we read the primary documentation, metadata
or code, or ran the tool), `source claim` (a scan read the paper's text) or
`unverified` (a scan's finding not yet checked here). Question tags are the
scans' inference unless stated.
