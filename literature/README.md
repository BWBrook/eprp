# Literature orientation

Keep concise, question-led synthesis notes here. Start a dated note for an
actual search/read tranche; do not create an empty note for every possible topic.
Use [the evidence conventions](../docs/evidence.md).

Each synthesis should identify the question, search route and limits, key
primary sources and access depth, competing findings, methodological weaknesses,
data/code leads, and implications for an idea or next check. A compact table of
sources is enough until a larger bibliography earns its own format. Retain
DOIs or other stable identifiers; avoid duplicate hand-maintained catalogues.

The API/package papers linked in [resources](../resources/README.md) are
infrastructure reading leads. They are not yet a scientific literature review.
There are currently no completed paper summaries in EPRP.
